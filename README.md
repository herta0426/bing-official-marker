# bing-official-marker
## Baidu Dream Our Bings - official site mark from Baidu
## 基于百度的Bing官网标签体验优化


[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-brightgreen)](https://www.tampermonkey.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

当您在必应（Bing）搜索时，本脚本从百度搜索结果中提取官方网站认证信息，为必应结果页中的对应条目添加 **官网参考**、**需确认** 或风险标签，并将缺失的链接以“百度认证参考”形式补充到列表顶部。
（百度结果可能缺失官网）这时候请你自行判断 不要过度依赖结果 脚本几乎纯AI编写 如果不愿意使用可以不用 可以借鉴思路编写更好的项目

---

## 功能特点

- **智能提取**：从百度结果页的 `mu`、`data-landurl` 或 `data-click` 属性中解析真实 URL，绕过百度跳转链接。
- **虚假链接过滤**：自动过滤广告、追踪、跳转等非正常链接（如 `nourl.ubs.baidu.com`、`e.baidu.com` 等）。
- **两级匹配机制**：
   - **完全匹配**（HTTPS 主机名完全相同）→ 标记为“官网参考”（蓝色标签）。
   - **主域匹配**（主域名相同但子域不同）→ 标记为“需确认”（橙色标签），点击前展示目标域名。
   - **高风险 URL**（HTTP、IP、短链接、异常端口、凭据 URL 或显式跳转）→ 无论是否匹配百度认证，默认阻止点击并展示风险原因。
   - **未验证结果**（没有匹配到百度认证主机名）→ 点击前要求确认，避免把普通搜索结果误认为官方站点。
- **补全缺失官网**：若必应结果中未出现百度认证的官网，则将其插入到搜索结果列表**最顶部**，并附带来源说明。
- **轻量静默**：后台运行，不干扰正常浏览。

## 安装与使用

### 安装步骤

1. 确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome/Edge）或 Greasemonkey（Firefox）。
2. 点击下方链接安装脚本（或新建脚本，粘贴源码）：
   - [安装脚本（GitHub）](https://github.com/herta0426/bing-official-marker/raw/refs/heads/main/baidudreamourbings.user.js)
3. 访问必应搜索页面（如 `https://cn.bing.com/search?q=微信`），脚本将自动运行。

### 使用说明

- 脚本无需配置，开箱即用。百度请求仅发送到 `www.baidu.com`，并请求使用匿名模式；相同关键词会在当前会话缓存最多 10 分钟。
- 搜索结果加载完成后，约 1~3 秒内会完成官网标记或补充。
- 若发现未生效，可刷新页面重试；或打开浏览器开发者工具（F12）查看控制台日志（`[官网补全]` 前缀）排查原因。

### 配置中心

在 Tampermonkey 扩展菜单中选择 **打开官网标记配置**，可以配置：

- 官网标记、未验证结果确认、高风险链接拦截和缓存时间。
- 天气、新闻、生活、娱乐、实时信息等排除词预设，以及自定义排除词。
- 百度、Google、DuckDuckGo、搜狗和 360 搜索的比对偏好。当前版本默认只实际抓取百度，其他引擎选项用于后续比对扩展。
- OpenAI、DeepSeek、通义千问和自定义 OpenAI 兼容接口的 AI 辅助分析。
- AI 模型通过 **获取模型列表** 按钮从当前服务商读取，读取后可从下拉框选择；选择 **自定义** 时才显示模型名称输入框。
- 默认使用“下载保护”模式：普通天气、新闻、音乐等搜索只标记不弹窗；检测到下载关键词或下载文件链接时才要求确认。也可在配置中切换“严格保护”或“仅标记”。

API Key 通过 Tampermonkey 扩展存储保存在本机，不写入仓库。AI 只接收搜索词、标题、域名和 URL，不接收网页正文；AI 结果仅作提示，不能解除本地高风险拦截。自定义接口还需要目标服务允许当前 Bing 页面跨域访问；预设服务使用用户脚本的跨域请求权限。

## 注意事项与常见问题

### 1. 重复标签或插入位置异常

- 脚本只会移除自身生成的标签（`[data-bom-tag="true"]`）和补充结果（`[data-bom-injected="true"]`），避免影响其他扩展。
- 插入位置为 `ol#b_results` 或 `.b_results` 容器的 **最前面**（`prepend`），不会打乱原有顺序。
- 若必应界面有重大改版（如搜索结果容器变化），脚本可能无法定位容器，此时会放弃插入并记录日志。

### 2. 需确认与风险链接

- 当百度认证的官网主域名与必应结果一致，但子域名不同时（如 `www.weixin.qq.com` vs `work.weixin.qq.com`），脚本会以橙色“需确认”标签提示，并在点击时要求确认。
- HTTP、IP 地址、短链接、异常端口、包含登录凭据或明显跳转参数的链接会被视为高风险，默认不会直接打开。
- “官网参考”只表示域名与百度认证结果一致，不代表页面没有被入侵，也不代表后续跳转安全。
