# Baidu Dream Our Bings - official site mark from Baidu
# 基于百度的Bing官网标签体验优化


[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-brightgreen)](https://www.tampermonkey.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

当您在必应（Bing）搜索时，本脚本自动从百度搜索结果中提取官方网站认证信息，为必应结果页中的对应条目添加 **官方** 或 **疑似官网** 标签，并将缺失的官网链接补充到列表顶部。
（百度结果可能缺失官网）这时候请你自行判断 不要过度依赖结果 脚本几乎纯AI编写 如果不愿意使用可以不用 可以借鉴思路编写更好的项目

---

## 功能特点

- **智能提取**：从百度结果页的 `mu`、`data-landurl` 或 `data-click` 属性中解析真实 URL，绕过百度跳转链接。
- **虚假链接过滤**：自动过滤广告、追踪、跳转等非正常链接（如 `nourl.ubs.baidu.com`、`e.baidu.com` 等）。
- **两级匹配机制**：
  - **完全匹配**（域名完全相同）→ 标记为“官网”（蓝色标签）。
  - **主域匹配**（主域名相同但子域不同）→ 标记为“疑似官网”（橙色标签），并悬浮提示认证主域。
- **补全缺失官网**：若必应结果中未出现百度认证的官网，则将其插入到搜索结果列表**最顶部**，并附带来源说明。
- **轻量静默**：后台运行，不干扰正常浏览。

## 安装与使用

### 安装步骤

1. 确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome/Edge）或 Greasemonkey（Firefox）。
2. 点击下方链接安装脚本（或新建脚本，粘贴源码）：
   - [安装脚本（raw）](https://raw.githubusercontent.com/herta0426/bing-official-marker/main/src/baidudreamourbings.user.js)
3. 访问必应搜索页面（如 `https://cn.bing.com/search?q=微信`），脚本将自动运行。

### 使用说明

- 脚本无需配置，开箱即用。
- 搜索结果加载完成后，约 1~3 秒内会完成官网标记或补充。
- 若发现未生效，可刷新页面重试；或打开浏览器开发者工具（F12）查看控制台日志（`[官网补全]` 前缀）排查原因。

## 注意事项与常见问题

### 1. 重复标签或插入位置异常

- 脚本会移除已存在的旧官方标签（`[data-official="true"]`），避免重复。
- 插入位置为 `ol#b_results` 或 `.b_results` 容器的 **最前面**（`prepend`），不会打乱原有顺序。
- 若必应界面有重大改版（如搜索结果容器变化），脚本可能无法定位容器，此时会放弃插入并记录日志。

### 2. 疑似官网的判定

- 当百度认证的官网主域名与必应结果一致，但子域名不同时（如 `www.weixin.qq.com` vs `work.weixin.qq.com`），脚本会以橙色“疑似官网”标签提示。
